## For agents (required)

- Primary index: `.devcouncil/repo_map.json` (also via MCP `devcouncil_repo_map`).
- Symbol graph: `dev graph query|trace|impact|dead` or MCP `devcouncil_graph_*` / `devcouncil_code_*`.
- Ownership boundaries in this file; refresh the machine map with `dev map` / `pnpm map`.
- Do not use GitNexus or Graphify in this repo.

## Recommended Search Pattern for Edits

1. Run `dev map --if-stale` (or `dev map` after large structural changes).
2. Open `.devcouncil/repo_map.json` for subsystems, entry roots, and neighbors.
3. Use `dev graph query` / `dev graph impact` for callers and blast radius.
4. Inspect only the owning boundary first, then touch the smallest surface.
